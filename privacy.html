プライバシーポリシー

Hermes（家族用アシスタント） ・ 制定日 2026年10月20日 ・ 改定日 2026年10月21日（ドライブの読み取りを追加）

Hermes は、ひとつの家庭のためだけに動かしている個人用のアシスタントです。このページでは、Google アカウントと連携したときに扱うデータと、その扱い方を説明します。

1. 利用する人

利用できるのは、運営者とその家族だけです。一般の方には提供していません。

2. Google から受け取るデータ

  • Google カレンダー：家族が許可したカレンダーの予定（タイトル、日時、場所、説明）
  • Google スプレッドシート：Hermes が作成したスプレッドシートと、家族がリンクを送って編集を許可したスプレッドシートの内容（読み書き）
  • Google ドライブ（読み取り）：家族から頼まれたときに、ドライブ内のファイルを探して内容を読みます（読み取りのみ）
  • Google ドライブ（書き込み）：新しいファイルの作成と更新は、Hermes が作成したフォルダとファイルの中だけで行います

家族が保存したファイルを Hermes が変更・削除することはありません。例外は、家族がリンクを送って編集を明示的に許可したスプレッドシートだけで、許可はいつでも取り消せます。Gmail と連絡先には、許可を求めず、アクセスもしません。

3. データの使い道

受け取ったデータは、家族から頼まれた次のことにだけ使います。

  • 予定の登録・確認・変更
  • タスクの追加・一覧表示・完了の記録
  • 予定やタスクのリマインド
  • 頼まれた調べものの結果や作成物を、家族のドライブ内の Hermes 用フォルダに保存・更新すること
  • 頼まれたときに、ドライブ内のファイルを探して内容を読み、要約や分析をすること

広告、販売、プロファイリング、AIモデルの学習には使いません。

4. 保存する場所

Google の認証情報は、家庭内のパソコンの中に保存し、暗号化された通信で Google とやり取りします。予定やタスクの内容は Google のサービス上に保存され、運営者のパソコンには処理に必要な間だけ置かれます。

5. 第三者への提供

Google から受け取ったデータを、第三者に販売・提供することはありません。ただし、依頼への返事を作るために、内容の一部をAIサービス（Anthropic 社の Claude API）に送ることがあります。このとき送るのは、その依頼の処理に必要な範囲だけです。

6. Google API サービスのユーザーデータに関するポリシー

Hermes による Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

7. 連携をやめるとき

いつでも Google アカウントの「サードパーティ製のアプリとサービス」 から Hermes へのアクセスを取り消せます。取り消すと、Hermes は以後データにアクセスできなくなり、保存していた認証情報も削除します。

このページについてのお問い合わせは、運営者の GitHub @hk1226 までご連絡ください。

English summary

Hermes is a private assistant used only by one household. With the family's consent it reads and writes their Google Calendar events and Google Sheets spreadsheets, reads Google Drive files when asked (read-only), writes only to Drive files and folders it created itself, and edits other spreadsheets only after the family explicitly allows a specific spreadsheet, solely to manage the family's schedule, tasks, reminders and requested research results. Data is never sold, shared for advertising, or used to train AI models. Parts of a request may be sent to Anthropic's Claude API only to answer that request. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account permissions page.
